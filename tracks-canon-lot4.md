# Lot 4 : propositions issues de la passe, filtrees

Le classement Last.fm est bruyant : Charli xcx sort en acid house, Bjork en
gabber. On ne garde donc que les artistes QUE L'ATLAS RECONNAIT DEJA, soit
dans les artistes cles du genre, soit par un morceau DANS LA MEME FAMILLE.

La premiere version disait « ailleurs dans le corpus », ce qui etait trop
large : Kraftwerk passait en spacesynth parce quil est dans les Racines, et
The Weeknd en Hi-NRG. Un artiste peut exister dans latlas sans appartenir a
la famille examinee.

Les rééditions sont ecartees, et le suffixe apres un tiret est ignore dans
la comparaison : « Acid Tracks - 12 Version » est le meme morceau
qu'« Acid Tracks », et il passait a travers le dedoublonnage.

Les morceaux presents ailleurs dans le corpus sont ecartes : ce sont des
partages a declarer, pas des ajouts.

Annee laissee vide : le script la releve lui-meme.
